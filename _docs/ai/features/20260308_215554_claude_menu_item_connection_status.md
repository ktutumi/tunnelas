# メニュー項目への接続ステータス表示

## 目的

- メニューバーのグループ項目とルール項目を見ただけで接続状態を把握できるようにする。

## 実装概要

- `RuleStatus` にメニュー表示用の状態文言、状態シンボル、アクセシビリティラベルを追加した。
- `GroupSnapshot` は配下ルールを集約し、`error > starting > running > stopped` の優先順位で状態を表す。
- メニューのグループ項目とルール項目は、新しい状態シンボルをアイコンとして使う。

## リスク

- 記号のみの表現は意味が伝わりにくいため、VoiceOver 向けに状態ラベルを付与した。

## 完了条件

- グループ項目とルール項目の双方で状態記号が見える。
- 4 状態を識別できる。
- テストが通る。
