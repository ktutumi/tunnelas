# メニューバー項目のコンパクト化と詳細のサブメニュー化

## 目的

- メニューバー初回表示の情報量を減らし、状況確認と主要操作に集中できるようにする。
- ルール詳細は階層メニューへ移し、macOS の標準メニュー体験に近づける。

## 実装概要

- `MenuBarExtra` を window スタイルから標準メニュー構成へ変更した。
- 最上位には全体ステータス、設定エラー、グループごとの要約、主要操作を配置した。
- グループ配下に一括操作、ルール配下に詳細情報と状態依存アクションを配置した。
- ランタイム状態の集計とメニュー表示補助を `RuntimeSnapshot` / `GroupSnapshot` / `RuleSnapshot` に追加した。

## リスクと対策

- SwiftUI のメニュー表現で情報量を増やしすぎると再び長くなるため、一次表示では詳細本文を出さない。
- 詳細ログの確認は既存の Logs ウィンドウへ誘導し、メニューに全ログは載せない。

## 完了条件

- 最上位メニューがコンパクトである。
- 詳細情報がグループ・ルールのサブメニューから参照できる。
- テストが通る。
