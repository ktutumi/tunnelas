# Lessons

## 2026-03-08

- GitHub 連携では `gh` CLI と GitHub MCP を同一視しない。読み取り可否と書き込み可否、認証経路、権限は別々に確認する。
- ユーザーから「MCP が使えるはず」と修正を受けたら、推測で説明を続けず `get_me` などの最小 API で即座に疎通確認する。
- `gh auth status` が sandbox 内で失敗しても、sandbox 外の `gh` は通る場合がある。Issue/PR 作成を止める前に昇格実行の可能性を確認する。
- ブランチ名は GitHub で扱いやすい lowercase の `feature/...` `fix/...` 形式を優先し、PascalCase や個人サフィックスは新規作成時に使わない。
- プロジェクトの運用ルールが会話上で与えられていても、repo 直下の `AGENTS.md` が無いなら実ファイルとして追加し、後続作業で参照できる状態にする。
- SwiftUI の `Menu` でサブメニュー項目に `Label` のアイコンを付けても、実際の macOS メニューでは表示されない場合がある。見えることが必須の状態表示は、項目タイトル文字列自体に含めて検証する。
